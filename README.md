# Evaluación 2

## Descripción

Se implementa una simulación de blockchain para el envío de mensajes entre dos servidores en un entorno virtual sin instalación local.

## Funcionamiento

* Se crea un bloque génesis
* Cada bloque contiene datos, timestamp y hash previo
* Se simula comunicación entre dos nodos
* Se valida la integridad de la cadena

## Tecnologías

* JavaScript
* Entornos online (Replit / JSFiddle)

## Ejecución

1. Abrir Replit
2. Crear proyecto en JavaScript
3. Pegar el código
4. Ejecutar y observar resultados en consola

## Resultados

Se evidencia cómo los bloques se enlazan mediante hashes, garantizando la integridad de la información.

## Conclusión

La tecnología blockchain permite asegurar datos de forma distribuida, evitando manipulaciones y garantizando confianza en los sistemas.
